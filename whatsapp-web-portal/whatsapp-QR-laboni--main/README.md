# WhatsApp Short Link QR Code Share (Accessible Web App)

> দৃষ্টি প্রতিবন্ধী ভাই-বোন এবং সকল ব্যবহারকারীর জন্য সহজে হোয়াটসঅ্যাপ শর্ট লিঙ্ক কিউআর কোড শেয়ারিং ও লাইভ স্ক্রিন ভিউ ওয়েব সার্ভিস।

---

## 🖼️ প্রফাইল লগো ও সোশ্যাল মিডিয়া লিংক প্রিভিউ সেটআপ (my-logo.jpg)

### ১. নতুন প্রফাইল ছবি আপলোড করার নিয়ম:
- আপনার গিটহাব রিপোজিটরির রুট ডিরেক্টরিতে (Root Directory) অথবা `public/` ফোল্ডারে আপনার কাঙ্ক্ষিত ছবিটি **`my-logo.jpg`** নামে আপলোড করুন বা রিপ্লেস করুন।
- গিটহাবে পুশ করার সাথে সাথে Render.com স্বয়ংক্রিয়ভাবে প্রজেক্টটি রিবিল্ড করে আপনার আপলোড করা `my-logo.jpg` ছবিটি প্রফাইল লোগোতে লাইভ করে দেবে।
- প্রফাইল লোগোর সাইজ আকর্ষণীয় ও স্পষ্ট করার জন্য আগের চেয়ে আরও বড় (`w-[84px] h-[84px]`) এবং প্রিমিয়াম রাউন্ডেড রিং বর্ডার ও শ্যাডো যুক্ত করা হয়েছে।

### ২. সোশ্যাল মিডিয়া লিংক প্রিভিউ (Facebook Messenger, WhatsApp, TikTok, etc.):
- যখনই আপনি এই ওয়েবসাইটের লিংক **WhatsApp, Facebook Messenger, TikTok, Facebook, Twitter, Telegram** ইত্যাদিতে শেয়ার করবেন, তখন স্বয়ংক্রিয়ভাবে আপনার প্রফাইল ছবি `my-logo.jpg` লিংক প্রিভিউ থাম্বনেইল হিসেবে দেখা যাবে।
- Express সার্ভার ও HTML মেটা ট্যাগে স্বয়ংক্রিয়ভাবে ফুল ডোমেইন URL সহ `og:image`, `og:image:secure_url`, এবং `twitter:image` ইনজেক্ট করা হয়।

## 📌 রেন্ডার (Render.com) এ Web Service হিসেবে লাইভ করার নির্দেশিকা

এই প্রজেক্টটিতে **Render.com** এ সরাসরি **Node.js Web Service** হিসেবে রান করার জন্য সম্পূর্ণ কনফিগারেশন (`render.yaml`, `server.ts`, এবং `start` স্ক্রিপ্ট) যুক্ত করা হয়েছে।

---

### ১. গিটহাবে পুশ করার ধাপসমূহ (Step-by-Step GitHub Push)

আপনার কম্পিউটারের টার্মিনাল বা কমান্ড প্রম্পটে প্রজেক্ট ফোল্ডারে গিয়ে নিচের কমান্ডগুলো চালান:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন (যদি পূর্বে না করা থাকে)
git init

# ২. মেইন ব্রাঞ্চ নির্বাচন করুন
git branch -M main

# ৩. সব ফাইল যুক্ত করুন
git add .

# ৪. কমিট করুন
git commit -m "feat: add my-logo profile and social share preview support"

# ৫. আপনার গিটহাব রিপোসিটরি লিঙ্ক যুক্ত করুন (YOUR_USERNAME ও YOUR_REPO পরিবর্তন করুন)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

### ২. Render.com এ ডিপ্লয় করার পদ্ধতি (Deploy on Render.com)

Render.com এ আপনি ২ভাবে ডিপ্লয় করতে পারেন:

#### পদ্ধতি ক: Blueprint (স্বয়ংক্রিয় - সবচেয়ে সহজ)
1. [Render.com](https://render.com) এ লগইন করুন।
2. ড্যাশবোর্ডে গিয়ে **"Blueprints"** মেনুতে ক্লিক করুন।
3. **"New Blueprint Instance"** নির্বাচন করে আপনার GitHub রিপোজিটরিটি কানেক্ট করুন।
4. Render স্বয়ংক্রিয়ভাবে প্রজেক্টের `render.yaml` ফাইল শনাক্ত করে সমস্ত কনফিগারেশন সেটআপ করে দেবে।
5. **"Apply"** বাটনে চাপ দিলেই আপনার Web Service লাইভ হয়ে যাবে!

---

#### পদ্ধতি খ: ম্যানুয়াল Web Service তৈরি (Manual Setup)
1. Render ড্যাশবোর্ডে গিয়ে **"New +"** বাটনে ক্লিক করে **"Web Service"** সিলেক্ট করুন।
2. আপনার GitHub রিপোজিটরিটি নির্বাচন করুন।
3. নিচের সেটিংসগুলো দিন:
   - **Name**: `whatsapp-qr-share` (বা আপনার পছন্দের নাম)
   - **Language / Runtime**: `Node`
   - **Branch**: `main`
   - **Region**: `Singapore` (বাংলাদেশ ও এশিয়ার জন্য দ্রুততম)
   - **Build Command**: 
     ```bash
     npm install --legacy-peer-deps && npm run build
     ```
   - **Start Command**: 
     ```bash
     npm start
     ```
   - **Plan**: `Free`
   - **Health Check Path**: `/healthz`
4. **"Deploy Web Service"** বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে এবং Render আপনাকে একটি ফ্রি HTTPS ডোমেইন (যেমন: `https://whatsapp-qr-share.onrender.com`) প্রদান করবে।

## ⚙️ প্রজেক্টের স্ক্রিপ্টসমূহ (Available Scripts)

- `npm run dev`: লোকাল ডেভেলপমেন্ট সার্ভার চালু করে (Port: 3000)
- `npm run build`: ক্লায়েন্ট সাইড এবং Node.js প্রোডাকশন সার্ভার (`dist/server.js`) বিল্ড করে
- `npm start`: প্রোডাকশন Express সার্ভার চালু করে (Render.com এর জন্য অপ্টিমাইজড)
- `npm run lint`: টাইপস্ক্রিপ্ট চেকিং
